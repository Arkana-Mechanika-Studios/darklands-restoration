Mods go here: one folder per mod, as you unzipped it (the folder that holds its mod.json), for example

  mods/wayside-shrine/mod.json

A mod is played only when you name it: --mod <name> on the command line, or "mods" in the settings file. More: docs/MODS.md.

The Darklands Workshop (a download of its own) comes with an example mod, in Workshop/examples/example-mod-wayside-shrine:
copy that folder here to try it. From 1.3 the Workshop makes mods here.

Unpacking a new version of the game over this one leaves this folder alone. Deleting the game's folder deletes it: keep a
copy of the mods you made.
