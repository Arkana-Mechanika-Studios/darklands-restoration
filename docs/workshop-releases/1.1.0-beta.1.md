The first beta of the Darklands Workshop, the editor for translation packs of the Darklands Restoration Project. It is a
download of its own; the game's releases are apart. Packs it saves record its version (`pack.json`, `"workshop"`).

What it does:

- Opens, makes and saves translation packs: every text of the game, in sections by where the game shows it, card texts in
  rows (your words only; markers, lead-ins and indents written for you).
- Draws each text as the game draws it, in the pack's fonts (pixel or TrueType), against its box or the card's foot.
- Checks the pack with the game's own check; plays the game with the pack at the text you are on.
- Screen layouts per language, Chinese, Japanese and Korean line breaking, a glossary, pack variables, notes for
  translators and AI.
- Exports and imports texts (JSON, CSV, XLIFF 2.0), Copy for AI and Paste result.
- Decorated capitals made by the pack, for letters the game has no picture of.

This is a beta: please report what goes wrong (the … menu, **Report a problem…**: a zip to attach to the report form;
nothing is sent).
